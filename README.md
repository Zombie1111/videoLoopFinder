# Video Loop Finder
AI generated tool thats finds the two most similar frames that are X-Y seconds apart. Somewhat user friendly.

## How To Use
-Clone the repository

-Run "install.bat" for install instructions and some stuff is installed automatically

-Replace "vidToLoop.mp4 REPLACEWITHREALVID" with the video you wanna loop. File should be named "vidToLoop.mp4"

-Check configuration "frameMatcher.config"

-Run "run.bat" and hope it works :)


## Purpose
I find this tool useful for making looping background videos. You may find it useful too :)
